# 💰 Continha

> os gastos da casa, sem complicação

App simples e moderno para registrar os gastos domésticos. Feito em um único arquivo HTML — sem instalação, sem servidor, funciona offline e salva tudo no próprio navegador.

## ✨ Recursos

- ➕ Registro de gastos com descrição, valor, data e categoria
- 🏷️ 8 categorias visuais (Mercado, Contas, Moradia, Transporte, Saúde, Lazer, Comida, Outros)
- 📊 Resumo do mês: total, número de lançamentos e média por dia
- 📈 Gráfico de gastos por categoria (valor e %)
- 🗓️ Filtro por mês
- 💾 Salvamento automático no navegador (`localStorage`)
- 📱 Layout responsivo (celular e computador)
- 🌙 Visual moderno em tema escuro

## 🚀 Como usar

Basta abrir o arquivo [`index.html`](index.html) no navegador. Não precisa instalar nada.

## 🛠️ Tecnologia

HTML, CSS e JavaScript puro (vanilla) — sem dependências.
